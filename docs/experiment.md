# Experiment protocol

Test whether distinct agents can elect leadership, coordinate work, and maintain renewable supplies. Smoke-test with 3–5 agents, then start a fresh world for the ten-agent baseline. Use the same seed and starting conditions for paired comparisons. Vary one factor per comparison and repeat each condition with recorded replicate seeds.

Observe leadership selection, resource bottlenecks, conflict resolution, and action following decisions. End at the configured duration or record an early termination reason. Log operator interventions with timestamps and exclude smoke tests from baseline results.
